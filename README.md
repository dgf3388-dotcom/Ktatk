# قطعتك — منصة طلبات توفير قطع الغيار

موقع ثابت (HTML/CSS/JS) + Supabase. لا سلة ولا دفع ولا حسابات عملاء.

## الملفات
- `index.html` الموقع العام (عربي/إنجليزي، نموذج الطلب بثلاث مراحل)
- `admin.html` لوحة الإدارة (تسجيل دخول Supabase Auth + صلاحية admin)
- `config.js` بيانات الاتصال (فارغة حتى تضيف بياناتك)
- `schema.sql` الجداول وRLS والتخزين ودالة إرسال الطلب
- `notify-whatsapp.ts` إشعار واتساب تلقائي (اختياري، غير مفعّل)

## التشغيل
1. أنشئ مشروعاً في Supabase ونفّذ `schema.sql` في SQL Editor.
2. من Authentication > Users أضف مستخدم الإدارة (بريد + كلمة مرور)، ثم نفّذ آخر سطر في `schema.sql` ببريده ليصبح مديراً.
3. ضع `SUPABASE_URL` و`anon key` في `config.js` (لا تضع service_role أبداً).
4. ارفع الملفات إلى أي استضافة ثابتة (Netlify / Vercel / Cloudflare Pages / GitHub Pages). في Authentication > URL Configuration أضف رابط موقعك.
5. اختبر: أرسل طلباً مع صور ← افتح `/admin.html` ← تحقق من ظهوره وتعديل حالته.

## الأمان
- الزوار لا يملكون أي صلاحية قراءة على الجدول؛ الإرسال فقط عبر دالة `submit_part_request`.
- الصور في حاوية خاصة (5MB، JPG/PNG/WEBP)، تُعرض للإدارة فقط بروابط مؤقتة.
- القراءة والتعديل محصوران بجدول `admins` عبر RLS.

## واتساب
- الآن: زر واتساب في كل طلب داخل لوحة الإدارة يفتح محادثة برسالة جاهزة فيها رقم الطلب.
- الإشعارات التلقائية: لا تعمل إلا بعد إعداد WhatsApp Business Cloud API وأسرار `notify-whatsapp.ts` وربطها بـ Database Webhook.

## الشعار
الموقع يستخدم أيقونة ترس + اسم بخط Cairo. لاستخدام ملف الشعار الرسمي استبدل الـ SVG داخل `.logo` بوسم `<img src="logo.png">`.
